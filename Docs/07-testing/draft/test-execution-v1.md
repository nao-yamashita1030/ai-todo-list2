## 重要事項

**テストフェーズでは、テストがすべてOKになるまで、テスト実行・修正を繰り返し実施してください。**

- テストを実行し、失敗したテストがある場合は、原因を調査して修正を行います

- テストがすべてOKになった時点で、テストフェーズを完了とし、次のフェーズ（リリースフェーズ）に進みます
