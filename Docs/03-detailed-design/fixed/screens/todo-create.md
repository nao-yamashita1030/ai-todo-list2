# 画面詳細設計: TODO作成画面

## 基本情報

- **画面名**: TODO作成画面
- **画面ID**: TODO_CREATE
- **URL**: `/todos/new` または `/projects/[projectId]/todos/new`
- **説明**: 新しいTODOを作成する
- **対象ユーザー**: ログイン済みユーザー（プロジェクトへのアクセス権限が必要）

## 画面の目的

ユーザーが新しいTODOを作成し、必要な情報を入力する

## バリデーション

### 入力バリデーション

| 項目名 | バリデーション内容 | エラーメッセージ |
|-------|------------------|----------------|
| タイトル | 必須、1文字以上255文字以下 | "タイトルは1文字以上255文字以下で入力してください" |
| 説明 | 10000文字以下 | "説明は10000文字以内で入力してください" |
| ステータス | todo, in_progress, done のいずれか | "ステータスが不正です" |
| 優先度 | high, medium, low のいずれか | "優先度が不正です" |
| 期限日 | 日付形式（YYYY-MM-DD） | "期限日の形式が不正です" |
| プロジェクト | 必須、UUID形式 | "プロジェクトを選択してください" |
| カテゴリ | UUID形式 | "カテゴリが不正です" |
| タグ | UUIDの配列 | "タグが不正です" |

### ビジネスルールバリデーション

- プロジェクトへのアクセス権限があること
- カテゴリが存在し、プロジェクトに属していること
- タグが存在し、プロジェクトに属していること

## エラーハンドリング

### エラー表示方法

- バリデーションエラーは各フィールドの下に表示
- サーバーエラーは画面上部に表示

### エラーメッセージ

| エラーコード | エラーメッセージ | 表示位置 |
|------------|----------------|---------|
| E001 | ログインが必要です | 画面全体（ログイン画面にリダイレクト） |
| E002 | このプロジェクトにアクセスする権限がありません | 画面上部 |
| E101 | 入力データが不正です | 各フィールドの下 |
| E201 | 指定されたプロジェクトが見つかりません | 画面上部 |
| E301 | データの保存に失敗しました | 画面上部 |

- この画面 → [TODO一覧画面](./todo-list.md)（作成成功後）
- この画面 → [TODO詳細画面](./todo-detail.md)（作成成功後、オプション）

## 処理フロー

1. 画面表示時
   - Server Componentでプロジェクト一覧を取得（プロジェクト選択用）
   - URLパラメータでプロジェクトIDが指定されている場合は、そのプロジェクトを選択
   - プロジェクトが選択されたら、Server Componentでカテゴリとタグの一覧を取得

2. プロジェクト選択時
   - 選択されたプロジェクトのカテゴリとタグを取得
   - カテゴリとタグの選択肢を更新

3. フォーム送信時
   - バリデーション
   - Server ActionでTODOを作成
   - 作成成功後、TODO一覧画面に遷移（またはTODO詳細画面に遷移）

4. キャンセルボタンクリック時
   - TODO一覧画面に戻る

## 状態管理

### 画面状態

- `formData`: フォームデータ
- `projects`: プロジェクト一覧
- `categories`: カテゴリ一覧
- `tags`: タグ一覧
- `errors`: バリデーションエラー
- `loading`: ローディング状態
- `submitting`: 送信中状態

### データ取得

- Server Componentで初期データを取得
- プロジェクト選択時にServer Componentでカテゴリ・タグを取得
- フォーム送信時はServer Actionを使用

## レスポンシブデザイン

### デスクトップ（1024px以上）

- 2カラムレイアウト（ラベルと入力欄を横並び）

### タブレット（768px - 1023px）

- 1カラムレイアウト

### スマートフォン（767px以下）

- 1カラムレイアウト
- 入力欄を全幅表示

## アクセシビリティ

### キーボード操作

- Tabキーで各要素にフォーカス移動
- Enterキーでフォームを送信
- Escキーでキャンセル

### スクリーンリーダー対応

- 各入力欄に適切なaria-labelを設定
- 必須項目にaria-requiredを設定
- エラーメッセージにaria-describedbyを設定

## 注意事項

- プロジェクトへのアクセス権限がない場合はエラーメッセージを表示
- カテゴリとタグはプロジェクト選択後に取得
- フォーム送信中は送信ボタンを無効化
