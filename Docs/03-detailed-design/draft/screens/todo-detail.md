# 画面詳細設計: TODO詳細画面

## 基本情報

- **画面名**: TODO詳細画面
- **画面ID**: TODO_DETAIL
- **URL**: `/todos/[todoId]` または `/projects/[projectId]/todos/[todoId]`
- **説明**: TODOの詳細情報、コメント、変更履歴を表示
- **対象ユーザー**: ログイン済みユーザー（TODOへのアクセス権限が必要）

## 画面の目的

ユーザーがTODOの詳細情報を確認し、コメントを追加・閲覧し、変更履歴を確認する

### レイアウト説明

- **ヘッダー**: ログイン情報、ナビゲーション
- **アクションボタンエリア**: 戻る、編集、削除ボタン
- **TODO詳細情報エリア**: TODOの基本情報を表示
- **コメント一覧エリア**: コメントの一覧と追加フォーム
- **変更履歴エリア**: TODOの変更履歴を表示
- **フッター**: コピーライトなど

## バリデーション

### 入力バリデーション

| 項目名 | バリデーション内容 | エラーメッセージ |
|-------|------------------|----------------|
| コメント内容 | 必須、1文字以上10000文字以下 | "コメント内容は1文字以上10000文字以下で入力してください" |

### ビジネスルールバリデーション

- TODOへのアクセス権限があること
- コメント追加時はTODOへのアクセス権限が必要

## エラーハンドリング

### エラー表示方法

- エラーメッセージを画面上部に表示
- データ取得エラーの場合はエラーページを表示

### エラーメッセージ

| エラーコード | エラーメッセージ | 表示位置 |
|------------|----------------|---------|
| E001 | ログインが必要です | 画面全体（ログイン画面にリダイレクト） |
| E002 | このTODOにアクセスする権限がありません | 画面上部 |
| E201 | 指定されたTODOが見つかりません | 画面上部 |
| E301 | データの取得に失敗しました | 画面上部 |

## 処理フロー

1. 画面表示時
   - Server ComponentでTODO詳細を取得
   - Server Componentでコメント一覧を取得
   - Server Componentで変更履歴を取得
   - ユーザーがアクセス可能なTODOか確認

2. 編集ボタンクリック時
   - TODO編集画面に遷移

3. 削除ボタンクリック時
   - 確認ダイアログを表示
   - 確認後、Server ActionでTODOを削除
   - 削除成功後、TODO一覧画面に遷移

4. コメント送信時
   - バリデーション
   - Server Actionでコメントを作成
   - コメント一覧を更新

## 状態管理

### 画面状態

- `todo`: TODO詳細データ
- `comments`: コメント一覧データ
- `histories`: 変更履歴データ
- `commentContent`: コメント入力内容
- `loading`: ローディング状態
- `error`: エラー状態

### データ取得

- Server Componentで初期データを取得
- コメント追加時はServer Actionを使用

## レスポンシブデザイン

### デスクトップ（1024px以上）

- 2カラムレイアウト（TODO詳細情報とコメント・履歴を横並び）

### タブレット（768px - 1023px）

- 1カラムレイアウト
- コメントと履歴をタブで切り替え

### スマートフォン（767px以下）

- 1カラムレイアウト
- コメントと履歴をタブで切り替え

## アクセシビリティ

### キーボード操作

- Tabキーで各要素にフォーカス移動
- Enterキーでコメントを送信
- Escキーで確認ダイアログを閉じる

### スクリーンリーダー対応

- 各要素に適切なaria-labelを設定
- コメント入力欄にaria-describedbyを設定

## 注意事項

- TODOへのアクセス権限がない場合はエラーメッセージを表示
- コメントはリアルタイム更新は必要に応じて実装
- 変更履歴は時系列で表示（新しい順）
