# 画面詳細設計: プロジェクト編集画面

## 基本情報

- **画面名**: プロジェクト編集画面
- **画面ID**: PROJECT_EDIT
- **URL**: `/projects/[projectId]/edit`
- **説明**: 既存のプロジェクトを編集する
- **対象ユーザー**: ログイン済みユーザー（プロジェクトへの編集権限が必要、オーナーのみ）

## 画面の目的

ユーザーが既存のプロジェクトを編集し、情報を更新する

## レイアウト

### 画面構成

```
┌─────────────────────────────────┐
│           ヘッダー               │
├─────────────────────────────────┤
│ [戻る]                           │
├─────────────────────────────────┤
│                                 │
│     プロジェクト編集フォーム    │
│  ┌─────────────────────────┐   │
│  │ プロジェクト名 *         │   │
│  │ [入力欄]                 │   │
│  │                         │   │
│  │ 説明                     │   │
│  │ [テキストエリア]         │   │
│  │                         │   │
│  │ [キャンセル] [更新]      │   │
│  └─────────────────────────┘   │
│                                 │
├─────────────────────────────────┤
│           フッター               │
└─────────────────────────────────┘
```

### レイアウト説明

- **ヘッダー**: ログイン情報、ナビゲーション
- **戻るボタン**: プロジェクト一覧画面に戻る
- **プロジェクト編集フォーム**: プロジェクトの情報を編集するフォーム
- **フッター**: コピーライトなど

## 画面要素

### プロジェクト名入力欄

- **要素名**: プロジェクト名入力欄
- **種類**: 入力欄
- **位置**: フォーム上部
- **説明**: プロジェクト名を編集
- **初期値**: 既存のプロジェクトの名前
- **必須/任意**: 必須

### 説明入力欄

- **要素名**: 説明入力欄
- **種類**: テキストエリア
- **位置**: プロジェクト名入力欄の下
- **説明**: プロジェクトの説明を編集
- **初期値**: 既存のプロジェクトの説明
- **必須/任意**: 任意

### キャンセルボタン

- **要素名**: キャンセルボタン
- **種類**: ボタン
- **位置**: フォーム下部
- **説明**: 編集をキャンセルしてプロジェクト一覧画面に戻る
- **初期値**: -
- **必須/任意**: 任意

### 更新ボタン

- **要素名**: 更新ボタン
- **種類**: ボタン
- **位置**: フォーム下部
- **説明**: プロジェクトを更新
- **初期値**: -
- **必須/任意**: 任意

## バリデーション

### 入力バリデーション

| 項目名 | バリデーション内容 | エラーメッセージ |
|-------|------------------|----------------|
| プロジェクト名 | 必須、1文字以上255文字以下 | "プロジェクト名は1文字以上255文字以下で入力してください" |
| 説明 | 10000文字以下 | "説明は10000文字以内で入力してください" |

### ビジネスルールバリデーション

- プロジェクトへの編集権限があること（オーナーのみ）
- プロジェクトが存在すること

## エラーハンドリング

### エラー表示方法

- バリデーションエラーは各フィールドの下に表示
- サーバーエラーは画面上部に表示

### エラーメッセージ

| エラーコード | エラーメッセージ | 表示位置 |
|------------|----------------|---------|
| E001 | ログインが必要です | 画面全体（ログイン画面にリダイレクト） |
| E002 | このプロジェクトを編集する権限がありません | 画面上部 |
| E101 | 入力データが不正です | 各フィールドの下 |
| E201 | 指定されたプロジェクトが見つかりません | 画面上部 |
| E301 | データの更新に失敗しました | 画面上部 |

## 画面遷移

### 遷移元

- [プロジェクト一覧画面](./project-list.md) → この画面

### 遷移先

- この画面 → [プロジェクト一覧画面](./project-list.md)（更新成功後）

## 処理フロー

1. 画面表示時
   - Server Componentでプロジェクト詳細を取得
   - フォームに既存のプロジェクトの情報を設定
   - ユーザーが編集権限（オーナー）があるか確認

2. フォーム送信時
   - バリデーション
   - Server Actionでプロジェクトを更新
   - 更新成功後、プロジェクト一覧画面に遷移

3. キャンセルボタンクリック時
   - プロジェクト一覧画面に戻る

## 状態管理

### 画面状態

- `project`: プロジェクト詳細データ
- `formData`: フォームデータ
- `errors`: バリデーションエラー
- `loading`: ローディング状態
- `submitting`: 送信中状態

### データ取得

- Server Componentで初期データを取得
- フォーム送信時はServer Actionを使用

## レスポンシブデザイン

### デスクトップ（1024px以上）

- 2カラムレイアウト（ラベルと入力欄を横並び）

### タブレット（768px - 1023px）

- 1カラムレイアウト

### スマートフォン（767px以下）

- 1カラムレイアウト
- 入力欄を全幅表示

## アクセシビリティ

### キーボード操作

- Tabキーで各要素にフォーカス移動
- Enterキーでフォームを送信
- Escキーでキャンセル

### スクリーンリーダー対応

- 各入力欄に適切なaria-labelを設定
- 必須項目にaria-requiredを設定
- エラーメッセージにaria-describedbyを設定

## 注意事項

- プロジェクトへの編集権限がない場合はエラーメッセージを表示
- オーナーのみが編集可能
- フォーム送信中は送信ボタンを無効化
