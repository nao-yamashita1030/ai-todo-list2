# 画面詳細設計: プロジェクト一覧画面

## 基本情報

- **画面名**: プロジェクト一覧画面
- **画面ID**: PROJECT_LIST
- **URL**: `/projects`
- **説明**: プロジェクトの一覧を表示し、検索・フィルタリングが可能
- **対象ユーザー**: ログイン済みユーザー

## 画面の目的

ユーザーがプロジェクトを一覧で確認し、検索・フィルタリング機能を使って目的のプロジェクトを素早く見つける

## レイアウト

### 画面構成

```
┌─────────────────────────────────┐
│           ヘッダー               │
├─────────────────────────────────┤
│ [検索バー] [新規作成]            │
├─────────────────────────────────┤
│                                 │
│       プロジェクト一覧          │
│  ┌─────────────────────────┐   │
│  │ プロジェクトアイテム1    │   │
│  └─────────────────────────┘   │
│  ┌─────────────────────────┐   │
│  │ プロジェクトアイテム2    │   │
│  └─────────────────────────┘   │
│                                 │
├─────────────────────────────────┤
│           フッター               │
└─────────────────────────────────┘
```

### レイアウト説明

- **ヘッダー**: ログイン情報、ナビゲーション
- **検索・新規作成エリア**: 検索バー、新規作成ボタン
- **プロジェクト一覧エリア**: プロジェクトアイテムのリスト
- **フッター**: コピーライトなど

## 画面要素

### 検索バー

- **要素名**: 検索バー
- **種類**: 入力欄
- **位置**: 画面上部
- **説明**: プロジェクト名や説明を検索
- **初期値**: 空
- **必須/任意**: 任意

### 新規作成ボタン

- **要素名**: 新規作成ボタン
- **種類**: ボタン
- **位置**: 検索バーの横
- **説明**: 新しいプロジェクトを作成
- **初期値**: -
- **必須/任意**: 任意

### プロジェクトアイテム

- **要素名**: プロジェクトアイテム
- **種類**: カード
- **位置**: プロジェクト一覧エリア
- **説明**: 各プロジェクトの情報を表示（プロジェクト名、説明、オーナー、メンバー数、TODO数、作成日時）
- **初期値**: -
- **必須/任意**: -

## バリデーション

### 入力バリデーション

| 項目名 | バリデーション内容 | エラーメッセージ |
|-------|------------------|----------------|
| 検索キーワード | 最大255文字 | "検索キーワードは255文字以内で入力してください" |

### ビジネスルールバリデーション

なし（検索・フィルタリングのみ）

## エラーハンドリング

### エラー表示方法

- エラーメッセージを画面上部に表示
- データ取得エラーの場合はエラーページを表示

### エラーメッセージ

| エラーコード | エラーメッセージ | 表示位置 |
|------------|----------------|---------|
| E001 | ログインが必要です | 画面全体（ログイン画面にリダイレクト） |
| E301 | データの取得に失敗しました | 画面上部 |

## 画面遷移

### 遷移元

- [TODO一覧画面](./todo-list.md) → この画面

### 遷移先

- この画面 → [プロジェクト詳細画面](./project-detail.md)（プロジェクトアイテムクリック時、将来的に実装）
- この画面 → [プロジェクト作成画面](./project-create.md)
- この画面 → [TODO一覧画面](./todo-list.md)（プロジェクトアイテムクリック時、そのプロジェクトのTODO一覧を表示）

## 処理フロー

1. 画面表示時
   - Server Componentでプロジェクト一覧を取得
   - ユーザーがアクセス可能なプロジェクトのみを取得（オーナーまたはメンバー）

2. 検索時
   - クライアントサイドでフィルタリング
   - 必要に応じてサーバーサイドで検索

3. プロジェクトアイテムクリック時
   - そのプロジェクトのTODO一覧画面に遷移

4. 新規作成ボタンクリック時
   - プロジェクト作成画面に遷移

## 状態管理

### 画面状態

- `projects`: プロジェクト一覧データ
- `searchKeyword`: 検索キーワード
- `loading`: ローディング状態
- `error`: エラー状態

### データ取得

- Server Componentで初期データを取得
- クライアントサイドでフィルタリング・検索

## レスポンシブデザイン

### デスクトップ（1024px以上）

- 3カラムレイアウト

### タブレット（768px - 1023px）

- 2カラムレイアウト

### スマートフォン（767px以下）

- 1カラムレイアウト

## アクセシビリティ

### キーボード操作

- Tabキーで各要素にフォーカス移動
- Enterキーでプロジェクトアイテムを選択
- Escキーで検索をクリア

### スクリーンリーダー対応

- 各要素に適切なaria-labelを設定
- 検索バーにaria-describedbyを設定

## 注意事項

- 大量のプロジェクトがある場合はページネーションを実装
- プロジェクトアイテムにはメンバー数やTODO数などの統計情報を表示
