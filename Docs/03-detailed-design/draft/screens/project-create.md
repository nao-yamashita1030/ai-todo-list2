# 画面詳細設計: プロジェクト作成画面

## 基本情報

- **画面名**: プロジェクト作成画面
- **画面ID**: PROJECT_CREATE
- **URL**: `/projects/new`
- **説明**: 新しいプロジェクトを作成する
- **対象ユーザー**: ログイン済みユーザー

## 画面の目的

ユーザーが新しいプロジェクトを作成し、必要な情報を入力する

## レイアウト

### 画面構成

```
┌─────────────────────────────────┐
│           ヘッダー               │
├─────────────────────────────────┤
│ [戻る]                           │
├─────────────────────────────────┤
│                                 │
│     プロジェクト作成フォーム    │
│  ┌─────────────────────────┐   │
│  │ プロジェクト名 *         │   │
│  │ [入力欄]                 │   │
│  │                         │   │
│  │ 説明                     │   │
│  │ [テキストエリア]         │   │
│  │                         │   │
│  │ [キャンセル] [作成]      │   │
│  └─────────────────────────┘   │
│                                 │
├─────────────────────────────────┤
│           フッター               │
└─────────────────────────────────┘
```

### レイアウト説明

- **ヘッダー**: ログイン情報、ナビゲーション
- **戻るボタン**: プロジェクト一覧画面に戻る
- **プロジェクト作成フォーム**: プロジェクトの情報を入力するフォーム
- **フッター**: コピーライトなど

## 画面要素

### プロジェクト名入力欄

- **要素名**: プロジェクト名入力欄
- **種類**: 入力欄
- **位置**: フォーム上部
- **説明**: プロジェクト名を入力
- **初期値**: 空
- **必須/任意**: 必須

### 説明入力欄

- **要素名**: 説明入力欄
- **種類**: テキストエリア
- **位置**: プロジェクト名入力欄の下
- **説明**: プロジェクトの説明を入力
- **初期値**: 空
- **必須/任意**: 任意

### キャンセルボタン

- **要素名**: キャンセルボタン
- **種類**: ボタン
- **位置**: フォーム下部
- **説明**: 作成をキャンセルしてプロジェクト一覧画面に戻る
- **初期値**: -
- **必須/任意**: 任意

### 作成ボタン

- **要素名**: 作成ボタン
- **種類**: ボタン
- **位置**: フォーム下部
- **説明**: プロジェクトを作成
- **初期値**: -
- **必須/任意**: 任意

## バリデーション

### 入力バリデーション

| 項目名 | バリデーション内容 | エラーメッセージ |
|-------|------------------|----------------|
| プロジェクト名 | 必須、1文字以上255文字以下 | "プロジェクト名は1文字以上255文字以下で入力してください" |
| 説明 | 10000文字以下 | "説明は10000文字以内で入力してください" |

### ビジネスルールバリデーション

- プロジェクト名の重複チェック（同じユーザー内で重複可能、将来的に制限する可能性あり）

## エラーハンドリング

### エラー表示方法

- バリデーションエラーは各フィールドの下に表示
- サーバーエラーは画面上部に表示

### エラーメッセージ

| エラーコード | エラーメッセージ | 表示位置 |
|------------|----------------|---------|
| E001 | ログインが必要です | 画面全体（ログイン画面にリダイレクト） |
| E101 | 入力データが不正です | 各フィールドの下 |
| E301 | データの保存に失敗しました | 画面上部 |

## 画面遷移

### 遷移元

- [プロジェクト一覧画面](./project-list.md) → この画面

### 遷移先

- この画面 → [プロジェクト一覧画面](./project-list.md)（作成成功後）
- この画面 → [TODO一覧画面](./todo-list.md)（作成成功後、作成したプロジェクトのTODO一覧を表示、オプション）

## 処理フロー

1. 画面表示時
   - フォームを初期化

2. フォーム送信時
   - バリデーション
   - Server Actionでプロジェクトを作成
   - 作成成功後、プロジェクト一覧画面に遷移（またはTODO一覧画面に遷移）

3. キャンセルボタンクリック時
   - プロジェクト一覧画面に戻る

## 状態管理

### 画面状態

- `formData`: フォームデータ
- `errors`: バリデーションエラー
- `loading`: ローディング状態
- `submitting`: 送信中状態

### データ取得

- フォーム送信時はServer Actionを使用

## レスポンシブデザイン

### デスクトップ（1024px以上）

- 2カラムレイアウト（ラベルと入力欄を横並び）

### タブレット（768px - 1023px）

- 1カラムレイアウト

### スマートフォン（767px以下）

- 1カラムレイアウト
- 入力欄を全幅表示

## アクセシビリティ

### キーボード操作

- Tabキーで各要素にフォーカス移動
- Enterキーでフォームを送信
- Escキーでキャンセル

### スクリーンリーダー対応

- 各入力欄に適切なaria-labelを設定
- 必須項目にaria-requiredを設定
- エラーメッセージにaria-describedbyを設定

## 注意事項

- プロジェクトの作成者は自動的にオーナーとして登録される
- フォーム送信中は送信ボタンを無効化
