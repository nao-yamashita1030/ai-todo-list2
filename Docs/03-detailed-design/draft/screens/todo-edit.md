# 画面詳細設計: TODO編集画面

## 基本情報

- **画面名**: TODO編集画面
- **画面ID**: TODO_EDIT
- **URL**: `/todos/[todoId]/edit`
- **説明**: 既存のTODOを編集する
- **対象ユーザー**: ログイン済みユーザー（TODOへの編集権限が必要）

## 画面の目的

ユーザーが既存のTODOを編集し、情報を更新する

## バリデーション

### 入力バリデーション

| 項目名 | バリデーション内容 | エラーメッセージ |
|-------|------------------|----------------|
| タイトル | 必須、1文字以上255文字以下 | "タイトルは1文字以上255文字以下で入力してください" |
| 説明 | 10000文字以下 | "説明は10000文字以内で入力してください" |
| ステータス | todo, in_progress, done のいずれか | "ステータスが不正です" |
| 優先度 | high, medium, low のいずれか | "優先度が不正です" |
| 期限日 | 日付形式（YYYY-MM-DD） | "期限日の形式が不正です" |
| カテゴリ | UUID形式 | "カテゴリが不正です" |
| タグ | UUIDの配列 | "タグが不正です" |

### ビジネスルールバリデーション

- TODOへの編集権限があること
- カテゴリが存在し、プロジェクトに属していること
- タグが存在し、プロジェクトに属していること

## エラーハンドリング

### エラー表示方法

- バリデーションエラーは各フィールドの下に表示
- サーバーエラーは画面上部に表示

### エラーメッセージ

| エラーコード | エラーメッセージ | 表示位置 |
|------------|----------------|---------|
| E001 | ログインが必要です | 画面全体（ログイン画面にリダイレクト） |
| E002 | このTODOを編集する権限がありません | 画面上部 |
| E101 | 入力データが不正です | 各フィールドの下 |
| E201 | 指定されたTODOが見つかりません | 画面上部 |
| E301 | データの更新に失敗しました | 画面上部 |

## 画面遷移

### 遷移元

- [TODO詳細画面](./todo-detail.md) → この画面

### 遷移先

- この画面 → [TODO詳細画面](./todo-detail.md)（更新成功後）
- この画面 → [TODO一覧画面](./todo-list.md)（キャンセル時）

## 処理フロー

1. 画面表示時
   - Server ComponentでTODO詳細を取得
   - Server Componentでカテゴリとタグの一覧を取得
   - フォームに既存のTODOの情報を設定
   - ユーザーが編集権限があるか確認

2. フォーム送信時
   - バリデーション
   - Server ActionでTODOを更新
   - 更新成功後、TODO詳細画面に遷移

3. キャンセルボタンクリック時
   - TODO詳細画面に戻る

## 状態管理

### 画面状態

- `todo`: TODO詳細データ
- `formData`: フォームデータ
- `categories`: カテゴリ一覧
- `tags`: タグ一覧
- `errors`: バリデーションエラー
- `loading`: ローディング状態
- `submitting`: 送信中状態

### データ取得

- Server Componentで初期データを取得
- フォーム送信時はServer Actionを使用

## レスポンシブデザイン

### デスクトップ（1024px以上）

- 2カラムレイアウト（ラベルと入力欄を横並び）

### タブレット（768px - 1023px）

- 1カラムレイアウト

### スマートフォン（767px以下）

- 1カラムレイアウト
- 入力欄を全幅表示

## アクセシビリティ

### キーボード操作

- Tabキーで各要素にフォーカス移動
- Enterキーでフォームを送信
- Escキーでキャンセル

### スクリーンリーダー対応

- 各入力欄に適切なaria-labelを設定
- 必須項目にaria-requiredを設定
- エラーメッセージにaria-describedbyを設定

## 注意事項

- TODOへの編集権限がない場合はエラーメッセージを表示
- プロジェクトは変更不可
- フォーム送信中は送信ボタンを無効化
