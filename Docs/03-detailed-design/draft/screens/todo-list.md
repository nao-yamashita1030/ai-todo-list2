# 画面詳細設計: TODO一覧画面

## 基本情報

- **画面名**: TODO一覧画面
- **画面ID**: TODO_LIST
- **URL**: `/todos` または `/projects/[projectId]/todos`
- **説明**: TODOの一覧を表示し、検索・フィルタリングが可能
- **対象ユーザー**: ログイン済みユーザー

## 画面の目的

ユーザーがTODOを一覧で確認し、検索・フィルタリング機能を使って目的のTODOを素早く見つける

## レイアウト

### 画面構成

```
┌─────────────────────────────────┐
│           ヘッダー               │
├─────────────────────────────────┤
│ [検索バー] [フィルター] [新規作成] │
├─────────────────────────────────┤
│                                 │
│        TODO一覧                 │
│  ┌─────────────────────────┐   │
│  │ TODOアイテム1            │   │
│  └─────────────────────────┘   │
│  ┌─────────────────────────┐   │
│  │ TODOアイテム2            │   │
│  └─────────────────────────┘   │
│                                 │
├─────────────────────────────────┤
│           フッター               │
└─────────────────────────────────┘
```

### レイアウト説明

- **ヘッダー**: ログイン情報、ナビゲーション
- **検索・フィルターエリア**: 検索バー、フィルターボタン、新規作成ボタン
- **TODO一覧エリア**: TODOアイテムのリスト
- **フッター**: コピーライトなど

## 画面要素

### 検索バー

- **要素名**: 検索バー
- **種類**: 入力欄
- **位置**: 画面上部
- **説明**: TODOのタイトルや説明を検索
- **初期値**: 空
- **必須/任意**: 任意

### フィルターボタン

- **要素名**: フィルターボタン
- **種類**: ボタン（ドロップダウン）
- **位置**: 検索バーの横
- **説明**: ステータス、優先度、カテゴリ、タグでフィルタリング
- **初期値**: すべて表示
- **必須/任意**: 任意

### 新規作成ボタン

- **要素名**: 新規作成ボタン
- **種類**: ボタン
- **位置**: 検索バーの横
- **説明**: 新しいTODOを作成
- **初期値**: -
- **必須/任意**: 任意

### TODOアイテム

- **要素名**: TODOアイテム
- **種類**: カード
- **位置**: TODO一覧エリア
- **説明**: 各TODOの情報を表示（タイトル、ステータス、優先度、期限日、カテゴリ、タグ）
- **初期値**: -
- **必須/任意**: -

## バリデーション

### 入力バリデーション

| 項目名 | バリデーション内容 | エラーメッセージ |
|-------|------------------|----------------|
| 検索キーワード | 最大255文字 | "検索キーワードは255文字以内で入力してください" |

### ビジネスルールバリデーション

なし（検索・フィルタリングのみ）

## エラーハンドリング

### エラー表示方法

- エラーメッセージを画面上部に表示
- データ取得エラーの場合はエラーページを表示

### エラーメッセージ

| エラーコード | エラーメッセージ | 表示位置 |
|------------|----------------|---------|
| E001 | ログインが必要です | 画面全体（ログイン画面にリダイレクト） |
| E301 | データの取得に失敗しました | 画面上部 |

## 処理フロー

1. 画面表示時
   - Server ComponentでTODO一覧を取得
   - プロジェクトIDが指定されている場合は、そのプロジェクトのTODOのみを取得
   - ユーザーがアクセス可能なプロジェクトのTODOのみを取得

2. 検索時
   - クライアントサイドでフィルタリング
   - 必要に応じてサーバーサイドで検索

3. フィルター適用時
   - クライアントサイドでフィルタリング
   - ステータス、優先度、カテゴリ、タグでフィルタリング

4. TODOアイテムクリック時
   - TODO詳細画面に遷移

5. 新規作成ボタンクリック時
   - TODO作成画面に遷移

## 状態管理

### 画面状態

- `todos`: TODO一覧データ
- `filters`: フィルター条件
- `searchKeyword`: 検索キーワード
- `loading`: ローディング状態
- `error`: エラー状態

### データ取得

- Server Componentで初期データを取得
- クライアントサイドでフィルタリング・検索

## レスポンシブデザイン

### デスクトップ（1024px以上）

- 3カラムレイアウト
- サイドバーにフィルターを表示

### タブレット（768px - 1023px）

- 2カラムレイアウト
- フィルターをドロップダウンで表示

### スマートフォン（767px以下）

- 1カラムレイアウト
- フィルターをモーダルで表示

## アクセシビリティ

### キーボード操作

- Tabキーで各要素にフォーカス移動
- EnterキーでTODOアイテムを選択
- Escキーでフィルターを閉じる

### スクリーンリーダー対応

- 各要素に適切なaria-labelを設定
- 検索バーにaria-describedbyを設定

## 注意事項

- 大量のTODOがある場合はページネーションを実装
- リアルタイム更新は必要に応じて実装
