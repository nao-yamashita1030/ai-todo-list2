# API詳細仕様: コメント削除

## 基本情報

- **API名**: コメント削除
- **エンドポイント**: `/api/comments/[id]`
- **HTTPメソッド**: DELETE
- **バージョン**: v1
- **説明**: 既存のコメントを削除する

## 認証・認可

- **認証要件**: 必須
- **認可要件**: コメントへの削除権限が必要
- **権限**: コメントの作成者のみ

## リクエスト

### リクエストヘッダー

```
Content-Type: application/json
Authorization: Bearer {token}
```

### リクエストパラメータ

#### パスパラメータ

| パラメータ名 | 型 | 必須 | 説明 |
|------------|---|------|------|
| id | string (uuid) | ○ | コメントID |

#### クエリパラメータ
なし

#### リクエストボディ
なし

### リクエスト例

```bash
curl -X DELETE https://api.example.com/api/comments/123e4567-e89b-12d3-a456-426614174001 \
  -H "Authorization: Bearer {token}"
```

## レスポンス

### 成功レスポンス

**ステータスコード**: 200

```json
{
  "data": {
    "message": "コメントが正常に削除されました",
    "id": "123e4567-e89b-12d3-a456-426614174001"
  }
}
```

| フィールド名 | 型 | 説明 |
|------------|---|------|
| message | string | 成功メッセージ |
| id | string (uuid) | 削除されたコメントID |

### エラーレスポンス

**ステータスコード**: 401 / 403 / 404 / 500

```json
{
  "error": {
    "code": "E002",
    "message": "この操作を実行する権限がありません",
    "details": {}
  }
}
```

| エラーコード | ステータスコード | 説明 |
|------------|----------------|------|
| E001 | 401 | 認証が必要です |
| E002 | 403 | この操作を実行する権限がありません |
| E201 | 404 | 指定されたコメントが見つかりません |
| E301 | 500 | データベースエラーが発生しました |

## バリデーション

### 入力バリデーション

- `id`: 必須、UUID形式

### ビジネスルールバリデーション

- コメントへの削除権限があること（作成者のみ）
- コメントが存在すること

## 処理フロー

1. リクエストを受信
2. 認証チェック（Clerk）
3. コメントの存在確認
4. コメントへの削除権限を確認（作成者のみ）
5. コメントを削除
6. 成功レスポンスを返却

## 使用例

### 例1: コメント削除

```typescript
const response = await fetch('/api/comments/123e4567-e89b-12d3-a456-426614174001', {
  method: 'DELETE',
  headers: {
    'Content-Type': 'application/json',
  },
});

const data = await response.json();
```

## 注意事項

- コメントへの削除権限がない場合は403エラーを返却
- コメントが存在しない場合は404エラーを返却
- データベースエラーが発生した場合は500エラーを返却
