# ローカルアプリケーション動作確認ガイド

**作成日**: 2025年12月06日

## 確認項目

### 1. 開発サーバーの起動確認

開発サーバーが正常に起動しているか確認してください：

- **URL**: http://localhost:3000
- **ステータス**: 200 OK

### 2. 認証機能の確認

1. **サインイン画面**
   - URL: http://localhost:3000/sign-in
   - Clerkのサインイン画面が表示されることを確認

2. **サインアップ**
   - 新しいアカウントを作成
   - メールアドレスとパスワードでサインアップ
   - サインアップ後、ダッシュボードにリダイレクトされることを確認

3. **サインイン**
   - 既存のアカウントでサインイン
   - サインイン後、ダッシュボードにリダイレクトされることを確認

### 3. データベース接続の確認

1. **ユーザー情報の同期**
   - サインイン後、ユーザー情報がデータベースに正常に同期されることを確認
   - ブラウザの開発者ツールでエラーがないか確認

2. **データの取得**
   - プロジェクト一覧が正常に表示されることを確認
   - TODO一覧が正常に表示されることを確認

### 4. プロジェクト管理機能の確認

1. **プロジェクト一覧**
   - URL: http://localhost:3000
   - プロジェクト一覧が表示されることを確認
   - 検索機能が動作することを確認

2. **プロジェクト作成**
   - 「新規プロジェクト」ボタンをクリック
   - プロジェクト名と説明を入力
   - プロジェクトが正常に作成されることを確認

3. **プロジェクト編集**
   - プロジェクトを選択
   - プロジェクト名や説明を編集
   - 変更が正常に保存されることを確認

4. **プロジェクト削除**
   - プロジェクトを削除
   - プロジェクトが正常に削除されることを確認

### 5. TODO管理機能の確認

1. **TODO一覧**
   - プロジェクトを選択
   - TODO一覧が表示されることを確認
   - 検索・フィルタリング機能が動作することを確認

2. **TODO作成**
   - 「新規TODO」ボタンをクリック
   - TODOのタイトル、説明、優先度、期限などを入力
   - TODOが正常に作成されることを確認

3. **TODO編集**
   - TODOを選択
   - TODOの内容を編集
   - 変更が正常に保存されることを確認

4. **TODO削除**
   - TODOを削除
   - TODOが正常に削除されることを確認

5. **TODOステータス切り替え**
   - TODOのステータスを変更（todo → in-progress → done）
   - ステータスが正常に更新されることを確認

### 6. コメント機能の確認

1. **コメント表示**
   - TODO詳細画面でコメントが表示されることを確認

2. **コメント作成**
   - コメントを入力して送信
   - コメントが正常に作成されることを確認

3. **コメント編集**
   - 作成したコメントを編集
   - 変更が正常に保存されることを確認

4. **コメント削除**
   - コメントを削除
   - コメントが正常に削除されることを確認

### 7. エラーハンドリングの確認

1. **ネットワークエラー**
   - ネットワーク接続を切断
   - エラーメッセージが適切に表示されることを確認

2. **バリデーションエラー**
   - 無効なデータを入力
   - バリデーションエラーメッセージが表示されることを確認

### 8. パフォーマンスの確認

1. **ページ読み込み速度**
   - 各ページの読み込み速度を確認
   - 3秒以内に読み込まれることを確認

2. **データ取得速度**
   - プロジェクト一覧、TODO一覧の取得速度を確認
   - 1秒以内にデータが表示されることを確認

## 確認結果の記録

確認が完了したら、以下の情報を記録してください：

- 確認日時
- 確認した項目
- 発見した問題（あれば）
- 修正内容（あれば）
